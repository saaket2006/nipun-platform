Scoring Architecture

Hybrid Evaluation Engine

  • Configurable Weight Profiles: Tailors skill match, experience, education, and projects per job description.
  • Domain Entity Normalization: spaCy pipelines harmonize variant skill terminologies into a unified ontology.
  • Zero Data Bleed: Scoring runs operate within tenant-isolated memory contexts before DB writes.

Explainability & Resilience

Multi-Model Gemini XAI

  • Ordered Failover: Cascades from gemini-3.5-flash-lite to 2.5-flash-lite, flash-latest, then deterministic scoring.
  • Grounded Rationales: Generates actionable candidate feedback, specific skill gap alerts, and ATS remediation.
